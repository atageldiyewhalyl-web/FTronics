Design System

A light, single-world system for a Mannheim security-technology installer. Synthesised from three references — Bevel, Apple AirPods Pro and Bridge — then reduced to five constraints that are enforced, not suggested.

The five constraints

  • One accent colour. Never two.
  • The primary button is never the accent.
  • Headings 500–600 weight. Never bolder.
  • Tracking tightens as type grows.
  • Long pages are paid for with scroll choreography.

Token architecture

  • --ft-ink-900 — raw colour
  • --bg — semantic role
  • --btn-primary-bg — component property

Components read the semantic layer, never a raw hex. Retheming is a token swap, not a component rewrite.

Foundations

Colour

One accent, used at most twice per viewport. Everything else is neutral. Contrast ratios are computed live against white.

Raw neutrals

The single accent

Functional — never decorative

The rule that matters most

  • The current live site runs three accents — red, green and cyan — each with a glow, on a near-black ground. Every reference uses one, on light.
  • Green means “armed / online / success” only. It is never a call to action.
  • No glow tokens, no bloom shadows. Depth is surface + 1px border + a 3px lift.

Foundations

Typography

DM Sans throughout — one family for display and UI, the way Bevel and Bridge each run a single face. Weight 600 maximum. Letter-spacing tightens as size grows; line-height compresses to match.

German requirement

  • hyphens:auto with lang="de" — Videoüberwachungsanlage at 96px overflows a 1200px container otherwise.
  • text-wrap:balance on H1/H2 to prevent orphans in compound-heavy headlines.
  • Bottom margins in em: h1 .2 · h2 .3 · h3 .5 · h4 .8 · p 1.

Discipline

Do / Don’t

The system holds together only if these hold. Most are one-line rules that are easy to break by accident.

✓ Do

  • One accent, twice per viewport maximum.
  • Primary button near-black. Always.
  • Semibold 500–600 headlines.
  • Negative tracking that tightens as type grows.
  • dvh not vh for pinned stages.
  • Reveal once, never re-animate on scroll-up.
  • Reserve every media box with aspect-ratio.
  • Let one section carry the page.
  • text-wrap:balance on German display type.

✕ Don’t

  • Don’t keep three accent colours.
  • Don’t use glows or bloom for depth.
  • Don’t run infinite ambient animations.
  • Don’t hijack or block scroll. Ever.
  • Don’t smooth-scroll touch.
  • Don’t animate height / top / width / margin.
  • Don’t colour-code spec chips.
  • Don’t exceed five panels in a pinned stack.
  • Don’t put more than three scrubbed videos on a page.
  • Don’t let body copy exceed 680px.

Reduced motion is a hard gate

Pinned stacks collapse into a normal vertical stack. Scrubbed video freezes at its poster with a manual play control. Lenis never initialises. This is not a degraded experience — it is a complete, static, readable page.
